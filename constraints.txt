# The exact versions CI and the release builds install:
#
#   python -m pip install -r requirements.txt -c constraints.txt
#
# requirements.txt says what StreamSync needs; this says which release of
# each a build gets. Without it every build took whatever PyPI had that
# day, so a new upload could change a shipped app unannounced - websockets
# 16 and 17 already behave differently for the relay - and the 2.0.8 Macs
# went out with an older certifi than the Windows build did. These are the
# versions 2.0.8 shipped with.
#
# Raise a pin in a pull request of its own, so the tests and builds run on
# it first. certifi is the set of CA roots the apps' HTTPS trusts, the
# updater's included, so it wants raising now and then even when nothing
# has broken.
