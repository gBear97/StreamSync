StreamSync 2.0.1 is a maintenance release with no changes you'll notice. It exists to prove that 2.0 updates itself: if you have 2.0.0, the app offers this version, checks it against the release's signed checksums, and installs it.

## Updating

- **From 2.0.0:** accept the update offer in the app, or use **Settings > Check now**. Your settings are kept.
- **From 1.x:** follow the "Upgrading from 1.x" steps in the [2.0.0 release notes](https://github.com/gBear97/StreamSync/releases/tag/v2.0.0). On Windows that means installing the setup program once by hand.

## Files

- `StreamSync-2.0.1-windows-x64-<commit>-setup.exe` (Windows 64-bit)
- `StreamSync-2.0.1-arm64-<commit>.dmg` (Mac, Apple Silicon)
- `StreamSync-2.0.1-x86_64-<commit>.dmg` (Mac, Intel)
- `SHA256SUMS` and `SHA256SUMS.sig` (the checksums and their signature, which the app checks before installing)
