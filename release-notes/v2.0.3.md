StreamSync 2.0.3 makes the Mac's stream swap work, finds a stream in any browser tab on Windows, and fixes a few smaller things.

## What's new

- **Mac: the stream comes forward when you pause.** "Show the stream while the film is paused" never worked in the Mac app: macOS blocked it without asking. Now, the first time you pause, macOS asks whether StreamSync may control *System Events*. Choose **Allow**. You can change this later in **System Settings > Privacy & Security > Automation**.
- **Windows: a stream in any browser tab is found.** With **Stream window** set to Automatic, StreamSync used to find the stream only when the window's title mentioned Twitch or Kick, so a VOD named after its video was missed. Now, if exactly one browser window is open, it uses that one. With several open, it still doesn't guess. If your stream plays somewhere other than a browser, choose its window in **Settings > Stream window**, or StreamSync may bring your one browser window forward when you pause.
- **External VLC no longer stalls the window.** StreamSync's window used to stop responding while it waited for a slow or stuck VLC to report the time. It now uses what VLC last reported, and if VLC stops answering, the film's clock stops instead of counting on.
- **Mac: macOS 14 (Sonoma) or later.** The Mac app has always needed macOS 14, and now it says so. On an older macOS, the Finder says the app needs a newer version of macOS instead of letting it crash.
- **Mac updates are ready for future macOS.** macOS 27 warns that the tool StreamSync uses to open an update's disk image is going away. Updates now fall back to its replacement, so they'll keep working when it's gone.
- **Watch party relay: a memory fix.** A connection could make the relay use more and more memory by sending film fingerprints under odd names. If you run a relay yourself, download `relay_server.py` again (see the README's [Relay server](https://github.com/gBear97/StreamSync#relay-server) section). The relay isn't part of the app, so updating the app doesn't update it.

## Updating

- **From 2.0.x:** accept the update offer in the app, or use **Settings > Check now**. Your settings are kept.
- **From 1.x:** follow the "Upgrading from 1.x" steps in the [2.0.0 release notes](https://github.com/gBear97/StreamSync/releases/tag/v2.0.0). On Windows that means installing the setup program once by hand.

On the Mac, the permission prompt appears the first time you pause with "Show the stream while the film is paused" on.
