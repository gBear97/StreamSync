StreamSync 2.0 is one app for Windows and the Mac in a new design, with signed updates and a real Windows installer.

## What's new

- **One app on both systems, in a new dark design.** Windows and the Mac share the same main window, Settings, Watch party and Update screens. A first-run screen walks you through opening the film. Once a film is open, one window shows the sync state, the player and fine-tune.
- **Signed updates.** Every release's `SHA256SUMS` is now signed (`SHA256SUMS.sig`, Ed25519). Before installing anything, the app checks that signature against the key built into it and checks the download against its checksum. If either check fails, it installs nothing and your copy stays as it was.
- **A Windows installer that updates itself.** The Windows download is now a per-user setup program (`...-windows-x64-...-setup.exe`). It installs to `%LOCALAPPDATA%\Programs\StreamSync` with no admin prompt, and from then on the app updates itself.
- **Update offers in the app.** A new version is offered in its own window, with a link to what's new, a progress bar and a Cancel button.
- **The film window on the Mac now works like the one on Windows.** Double-click for fullscreen, right-click (or Control-click) for a menu, and scroll for volume with an on-screen readout. In fullscreen, a control bar shows the timeline, Pause, Stop, -1 / +1 frame, Resync here and Resync (full).

## Removed

- **Video sync** (screen capture, capture region, facecam ignore zones, mirror toggle). Syncing is audio-only now, so the Mac no longer asks for Screen Recording permission.
- **The ±2 s nudge buttons.** Fine-tune steps by 0.1 s and 0.5 s, and the fullscreen bar steps one frame at a time.
- **F11.** Press **F** for fullscreen and **Esc** to leave it.
- **Global hotkeys** on Windows (Ctrl+Alt+S, R, P, Left, Right) and the Mac's menu shortcuts (Command-S, R, P). The app's own keys (Space, ← / →, F, Esc) work whenever one of its windows is in front.
- **The Windows zip.** Releases now ship the setup program instead.

## Upgrading from 1.x

**Windows (the 1.x zip): one manual install.** 1.x on Windows can't update itself, and 2.0 only updates a copy the installer put in place. So:

1. Download the `-setup.exe` below and run it. If SmartScreen says "Windows protected your PC", click **More info > Run anyway**. The installer isn't code-signed.
2. Start StreamSync from the Start menu and check that your film and settings are there.
3. Delete the old unzipped StreamSync folder.

Your settings are kept. They live in `.streamsync.json` in your home folder, not in the app's folder. Updates after this one come in the app.

**macOS:** 1.x offers 2.0 in the app as usual. Or open the `.dmg` (`arm64` for Apple Silicon, `x86_64` for Intel) and drag StreamSync.app over the old one in Applications, choosing **Replace**. If you're on 1.0.0 or 1.0.1, which can't reach GitHub, download it by hand.

## Antivirus note

To update itself on Windows, StreamSync downloads its own installer and runs it. It only runs an installer whose checksum matches the release's signed checksum list, but some antivirus tools flag any program that does this. If yours blocks an update, download the `-setup.exe` from this page and run it yourself. It updates the same installation.

## Known gaps

- **Mac, second screen:** fullscreen and the fullscreen bar on a second display haven't been tested on a Mac yet. If you try it, please open an issue saying what happened.

- `SHA256SUMS` and `SHA256SUMS.sig` (the checksums and their signature, which the app checks before installing)
